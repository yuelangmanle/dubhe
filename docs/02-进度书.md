## 4. 周记录

### W0 · 2026-10-23 → 2026-10-29（立项周）

**本周做了什么**

- 完成《Aether 自适应本地 AI 推理引擎开发书》v1.0：确定"不 fork 单一引擎、新建格式无关运行时"的路线，明确 ADRS / SSMgr / AKP / Sequence State 等 8 项原创方向，定义 AetherBench 的 workload、指标口径与反作弊规则。
- 完成《Aether 项目开发书（总纲）》v1.0：把引擎级 P0–P5 翻译为项目级 M0–M6（63 周），补齐产品层、宿主架构、进程模型、Git 治理、质量门禁、合规与商业边界。
- 建立 Git 仓库与文档体系（DEV / PRG / ADR / RFC 四层），首批 4 条 ADR 落档。
- 明确"不做什么"清单（§1.4），把范围蔓延的风险前置掐掉。

**关键决策**

| # | 决策 | 依据 |
| --- | --- | --- |
| D1 | 采用 monorepo，引擎与应用同仓 | ADR-0001 |
| D2 | 不 fork 单一引擎，新建运行时 | ADR-0002 |
| D3 | 文档用 Markdown 入 Git，docx 只作产物 | ADR-0004 |
| D4 | Mac 优先，Android 预研延后 6 周启动 | 避免 8 人双线都不深（R4） |

**下周计划（W1）**

1. 冻结 6 个竞品 commit，写入 `bench/baselines.lock`。
2. 定义 AetherBench manifest / result schema。
3. GGUF loader 开工。
4. 硬件采购下单。
5. 发布 3 个岗位 JD。

**阻塞与风险**

- 无硬阻塞。
- 观察项：M0 只有 4 周，但 AetherBench 客户端 120h + IR 160h + 两个 loader 280h，若团队在 W2 前不到 3 人，M0 出口必然滑期。**W2 结束若人数 < 3，触发范围裁剪：IR schema 降级为"仅 Compute + State"，Quant 图延到 M1。**
