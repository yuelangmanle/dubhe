# 品牌视觉与生图提示词

> **先读 `04-产品理念与品牌气质.md`。**
> 提示词只是执行层。把那份文档贴给 GPT 当背景，它才知道这是什么产品、为谁做、什么气质。
>
> 视觉基调：**小清新 + 高级克制**。墨绿 + 暖纸白，低饱和、高明度、大留白。

---

## 1. 色板（只有三个）

| 名称 | 色值 | 用在哪 |
| --- | --- | --- |
| 墨绿 | `#2E4238` | 图形本体、标题 |
| 纸白 | `#FAF8F3` | 底色（暖白，不是纯白） |
| 雾绿 | `#A7C0B2` | 极小面积：状态点、辅助线 |

---

## 2. 先画图标总表（最关键的一步）

**不要一个一个画。** 分 16 次画，风格一定会飘。
一次画一张 4×4 的图标总表，同一张图里的图标天然统一，之后切图就行。

```
A grid of 16 minimal line icons, 4 columns by 4 rows, evenly spaced with
generous padding, on a warm off-white background #FAF8F3.
All icons drawn with identical stroke weight, rounded caps and rounded joins,
in deep green #2E4238. Uniform optical size across all 16.

Row 1: a ringed planet | a hamburger menu (three horizontal lines) | a plus sign | sliders
Row 2: two opposing arrows | a paperclip | a terminal window with >_ | an upward arrow
Row 3: a rounded square | a lightning bolt | an X | an audio waveform
Row 4: a video camera | a document with a folded corner | a picture frame with a mountain | a checkmark

Flat vector, two colors only, no gradient, no glow, no shadow, no 3D,
no text labels, no numbers, no grid lines. 1024x1024.
```

出图之后按 4×4 等分切，每格就是一个图标。

---

## 3. Logo 本体

```
A brand mark for "Dubhe": a solid deep-green circle, with a thin ellipse ring
tilted 26 degrees that passes in front of the circle at the bottom and behind
it at the top, plus one small dot resting on the ring.

Flat vector, two colors only: deep green #2E4238 on warm off-white #FAF8F3.
No gradient, no glow, no shadow, no 3D, no text, no letters.
Centered, generous margin, nothing touching the edges. 1024x1024.
```

> 环要"从前面绕过去"而不是"贴在后面"——这一句是 logo 和普通圆环图标的区别。

如果要**反白版**（深底上用），把最后一句换成：

```
Inverted: warm off-white mark on a deep green #2E4238 background.
```

## 4. 单独画某一个图标时

如果总表里有不满意的要重画单个，用这个模板：

```
A single minimal line icon of <主体>, deep green #2E4238 on warm off-white #FAF8F3.
Identical stroke weight to a 24px icon set, rounded caps and joins, centered,
generous margin. Flat vector, two colors only, no gradient, no glow, no shadow,
no 3D, no text. 1024x1024.
```

`<主体>` 直接填：

| 图标 | 填这个 |
| --- | --- |
| 品牌 | `a solid circle with a tilted ellipse ring passing in front at the bottom` |
| 菜单 | `three horizontal lines, the bottom one slightly shorter` |
| 新建 | `a plus sign` |
| 设置 | `two horizontal sliders with round knobs` |
| API 网关 | `two opposing horizontal arrows` |
| 附件 | `a paperclip` |
| 工具调用 | `a terminal window containing a chevron and an underscore` |
| 发送 | `an upward arrow` |
| 停止 | `a rounded square` |
| 执行 | `a lightning bolt` |
| 关闭 | `an X` |
| 音频 | `an audio waveform of six vertical bars` |
| 视频 | `a video camera with a lens on the right` |
| 文件 | `a document with a folded top-right corner` |
| 图片 | `a picture frame with a small sun and a mountain` |
| 完成 | `a checkmark` |

## 5. 负面词（每条都带）

```
no gradient, no glow, no neon, no space background, no stars, no rainbow,
no glass ball, no 3D render, no text, no letters, no watermark
```

---

## 6. 验收

1. **缩到 24px 还认得出吗** —— 认不出就重画
2. **数颜色** —— 超过两个就不对
3. **笔画粗细一致吗** —— 16 个图标放一排，粗细要一样
4. **有没有字 / 水印**
5. **光学校大小一致吗** —— 有的图标画得满、有的画得小，放一起会参差

---

## 7. 出图之后：还是要转成矢量

界面里的图标必须是 SVG——位图在 2x/3x 屏会糊、不能跟随主题换色。
所以流程是：

```
生图出方向  →  按总表切图  →  我照着重绘成 SVG  →  替换 web/index.html 的 sprite
```

现在 `web/index.html` 里已经有一套手绘的 16 枚 `<symbol>`，等你的图出来，
我按新图的比例和细节重绘一遍就行，不用重新设计。

---

## 8. 切图规格（给安装包用）

**Android 自适应图标要两层**，不能是一张图：

| 层 | 尺寸 | 内容 |
| --- | --- | --- |
| 前景 | 432×432（108dp @4x） | 图形，透明底，只占中间 264×264 安全区 |
| 背景 | 432×432 | 纯 `#FAF8F3` |

**iOS / macOS**：1024 / 512 / 256 / 128 / 64 / 32 / 16，App Store 那张不能带透明通道。
