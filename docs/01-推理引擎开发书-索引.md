## 2. 已生效的关键结论（不可随意推翻）

1. **不 fork 单一引擎。** 新建格式无关运行时，按需吸收 llama.cpp / MLX / Locals / vLLM Metal / MNN 的局部能力。（ADR-0002）
2. **Mac 必须原生直读 GGUF 与 MLX 目录**，不把"先转换"当正式支持。
3. **Mac 与 Android 共用调度/状态/模型语义，不共用 Kernel。**
4. **B=1 与 B>1 是两个工况**，必须分别优化、分别验收。
5. **Sequence State 是一等公民**，不是"增强版 KVCache"。
6. **IR 拆三图**：Compute / Quant / State。（ADR-0003）
7. **AetherBench 在 P0 建立**，不允许"引擎写完再 benchmark"。
8. **性能必须先过 quality gate**，顺序不可颠倒。
9. **"超越所有引擎"改写为可验收目标**：核心矩阵 ≥80% 第一，任何战略场景落后 ≤10%。
