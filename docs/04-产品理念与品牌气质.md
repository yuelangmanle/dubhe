# 产品理念

---

## 一句话

**天枢（Dubhe）是一台装在自己设备里的大模型推理引擎——断网也能跑，数据一步都不出这台机器。**

---

## 它做什么

| 能力 | 说明 |
| --- | --- |
| 本地推理 | 在自己设备上跑大模型，不需要联网，不需要账号 |
| 多模态 | 文字、图片、视频、语音，都能直接喂给它 |
| 工具调用 | 能读文件、列目录、执行命令，不只是聊天 |
| API 网关 | 把本地模型变成一个 OpenAI 兼容的接口，别的程序可以调 |
| Agent | 能自己拆任务、调工具、多步完成 |

---

## 它怎么做到

**把硬件榨干。** 苹果 M 系列的 GPU 和神经网络引擎、骁龙的 NPU、天玑的 APU，全部用上。同样的模型，跑得比别人快。

**一个引擎，两个平台。** MacBook 和安卓手机共用一套代码，GGUF 和 MLX 两种格式都吃。

**全部自己写。** 从矩阵乘的 kernel 到 tokenizer 到 HTTP 服务，没有套壳，没有转手。

---

## 谁在用，什么时候用

- 飞机上、高铁上、机房断网的时候，还要干活
- 手里有不能上传的东西：合同、病历、源码、设计稿
- 想给本地模型接一个接口，但不想为此租一台云服务器
- 只是单纯不想每句话都被传出去

这些人不是极客。他们要的是**私密**，但不会为了私密忍受难用。

---

## 它的性格

**快。** 打开就能用，不等加载，不转圈。

**安静。** 它在后台转，转完就停。不弹窗，不提醒你它有多厉害。

**透明。** 界面里能直接看到 tok/s、看到它在调哪个工具、看到模型加载了什么。不藏。

**可靠。** 断网、切后台、锁屏，回来还在。

---

## 参照

**软件**：Things 3 的克制、Bear 的温度、Reeder 的安静、Halide 的专业感、Linear 的精确。

**物件**：Braun 的计算器、Teenage Engineering 的合成器、Muji 的收纳、Leica 的机身、天文年历的图谱。

**共同点**：都是工具，都做得很好，都不吵。
