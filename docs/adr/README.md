# 架构决策记录（ADR）

> 一条 ADR 只回答一件事：**在某个时间点，我们为什么选了这个方案，代价是什么。**
> 规则：**只追加，不覆盖。** 决策变了就新写一条，并在新条目里写 `Supersedes ADR-000X`，旧条目状态改为 `Superseded by ADR-000Y`。

## 模板

```markdown
# ADR-000N: 标题

- 状态：Proposed / Accepted / Superseded by ADR-000M / Deprecated
- 日期：YYYY-MM-DD
- 决策者：
- 关联：DUBHE-DEV-000 §X / RFC-000N

## 背景
（约束是什么，不做什么会出什么问题）

## 决策
（一句话说清选了什么）

## 备选方案
| 方案 | 优点 | 缺点 | 为什么没选 |

## 后果
（正面 / 负面 / 需要跟进的事）

## 复审条件
（什么情况下应该重新讨论这条决策）
```
